### 사용한 외부 API

기상청 단기예보 조회서비스 - 초단기실황조회 API를 사용합니다.

특정 날짜와 시간, 격자 좌표를 기준으로 기온·습도·강수량·풍속 등의 실황 데이터를 조회할 수 있으며,  
여러 지역의 격자 좌표를 반복 호출하여 대량 데이터를 수집합니다.

| 항목 | 내용 |
| --- | --- |
| Endpoint | `GET /getUltraSrtNcst` |
| 응답 형식 | JSON |
| 주요 요청값 | `base_date`, `base_time`, `nx`, `ny` |
| 주요 응답값 | 기온(T1H), 습도(REH), 강수량(RN1), 강수형태(PTY), 풍속(WSD), 풍향(VEC) |
